# 📊 Power BI Analyst — Desafio DIO

Projeto desenvolvido como parte do desafio prático do curso **Power BI Analyst**, da [DIO](https://www.dio.me/).

## 🎯 Sobre o projeto

O desafio tem como objetivo aplicar os conceitos apresentados durante o curso, utilizando o **Power BI** para criação, organização e análise de dados por meio de diferentes visualizações.

O projeto reproduz duas páginas apresentadas durante o curso e desenvolve uma terceira página de forma autoral, explorando diferentes tipos de visuais e recursos de interação do Power BI.
