# 📊 Data Analytics Portfolio

Bem-vindo ao meu portfólio de projetos em **Análise de Dados e Business Intelligence**.

Este repositório reúne projetos selecionados desenvolvidos durante minha evolução prática na área de dados, com foco na construção de análises, dashboards e relatórios capazes de transformar dados em informações claras e úteis para tomada de decisão.

Os projetos são adicionados e aprimorados conforme avanço nos estudos e desenvolvo novas habilidades.

---

## 🎯 Objetivo

Construir um portfólio prático e organizado que demonstre minha evolução em **Data Analytics**, reunindo projetos que envolvam análise, tratamento, visualização e interpretação de dados.

Cada projeto possui sua própria documentação, arquivos utilizados e contexto de desenvolvimento.

---

## 📂 Projetos

### 📈 Sales Dashboard — Power BI

Dashboard desenvolvido utilizando a base **Financial Sample**, explorando indicadores de vendas, unidades vendidas e lucro.

O projeto trabalha diferentes formas de visualização e organização das informações, incluindo análises por país e segmento.

**Principais práticas aplicadas:**

- Construção e organização de dashboards;
- Análise de vendas e lucratividade;
- Visualização geográfica de dados;
- Análise por segmentos;
- Formatação e organização de visuais;
- Tooltips e recursos de interação.

📁 [`power-bi-sales-dashboard`](./power-bi-sales-dashboard)

---

### 📊 Management Report — Power BI

Relatório gerencial desenvolvido em **Power BI** para análise de vendas e lucros, utilizando diferentes perspectivas e recursos de interação.

O projeto amplia a experiência com construção de relatórios, trabalhando navegação entre páginas, segmentação de dados e diferentes tipos de visualização.

**Principais práticas aplicadas:**

- Desenvolvimento de relatório gerencial;
- Navegação entre páginas;
- Segmentadores de dados;
- Análise de vendas e lucros;
- Organização visual das informações;
- Exploração de diferentes tipos de gráficos.

📁 [`power-bi-management-report`](./power-bi-management-report)

---

### 🗄️ Company Workforce Analysis — Power BI + PostgreSQL

Projeto de análise da estrutura organizacional de uma empresa, integrando **PostgreSQL** e **Power BI** em um fluxo completo de dados.

O desafio original utilizava MySQL no Azure. Nesta implementação, a infraestrutura foi adaptada para **PostgreSQL 16 no WSL2**, incluindo criação e carga do banco relacional, integração com o Power BI, transformação dos dados no Power Query e construção do relatório final.

**Principais práticas aplicadas:**

- Adaptação de scripts SQL para PostgreSQL;
- Modelagem e carga de banco de dados relacional;
- Integração PostgreSQL → Power BI;
- Transformação e limpeza com Power Query;
- Mesclagem de tabelas e autojunção para hierarquia funcionário/gestor;
- Tratamento de dados e valores nulos;
- Análise organizacional e construção de relatório.

📁 [power-bi-postgresql-company-analysis](./power-bi-postgresql-company-analysis)
