# Criando um Relatório Gerencial de Vendas com Power BI

Projeto desenvolvido como parte do desafio **Criando Um Relatório Gerencial de Vendas com Power BI**, da DIO.

## Objetivo

Construir um relatório mais elaborado utilizando a base **Financial Sample** do Power BI, aplicando recursos de visualização, navegação e interação entre páginas.

## O que foi desenvolvido

O projeto contém duas páginas de relatório.

### Página 1
- Estrutura visual personalizada
- Gráficos para análise de vendas
- Segmentadores de dados
- Botões de navegação
- Indicadores para alternância de visuais

### Página 2
- Análise detalhada de lucro
- Árvore de decomposição
- Treemap
- Gráfico de cascata
- Filtros por ano e país
- Navegação entre páginas

## Recursos utilizados

- Power BI Desktop
- Power Query
- Segmentadores de dados
- Indicadores
- Botões de navegação
- Árvore de decomposição
- Treemap
- Gráfico de cascata
- Filtros e interações entre visuais

## Dataset

Foi utilizada a base **Financial Sample**, disponibilizada para o desafio.
